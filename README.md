# KAKEN-ATLAS

**Kaken Atlas of Latent Academic Structures**
科研費データを用いた学術知識の構造化と研究評価の新指標開発

JSPS 科研費 基盤研究 (C) 採択課題（令和8〜10年度 / FY2026–2028）。
日本最大規模の学術データベースである科研費データに教師なし深層学習を適用し、
既存の306小区分に依存しない学術研究の潜在構造を解明する。さらに埋め込み空間での
位置から **新規性・架橋性・成長性** の3指標を開発し、引用を待たずに研究価値を評価する。

## 研究計画（年次）

| 年度 | テーマ | 主な作業 |
|------|--------|----------|
| **R8 (2026)** | データ基盤構築・埋め込み空間生成 | 科研費API約10万件取得 → 形態素解析 → BERT 768次元ベクトル化 → UMAP 3次元可視化 |
| **R9 (2027)** | 潜在構造の発見・新指標開発 | HDBSCANクラスタリング → 既存306小区分との乖離分析 → 3指標開発 |
| **R10 (2028)** | 実証実験・システム実証 | 全国URA約20名で評価実験 → Streamlit Webアプリ → API公開・論文投稿 |

## 技術スタック

- **言語 / 環境**: Python 3.12（[uv](https://docs.astral.sh/uv/) で管理）
- **形態素解析**: MeCab + NEologd 辞書
- **埋め込み**: 東北大BERT日本語版 (`cl-tohoku/bert-base-japanese-v3`, 768次元)
- **次元削減**: UMAP
- **クラスタリング**: HDBSCAN
- **可視化 / アプリ**: Streamlit
- **計算環境**: 開発=ローカル(Apple Silicon, CPU/MPS) / 大規模埋め込み=GPU（JAIST HAKUSAN 等）

## ディレクトリ構成

```
kaken-atlas/
├── src/kaken_atlas/   # ライブラリ本体
├── data/
│   ├── raw/           # 科研費APIの生データ（不変・git管理外）
│   ├── interim/       # 前処理途中（形態素解析・クレンジング後）
│   └── processed/     # 埋め込み・クラスタ等の成果物
├── scripts/           # データ取得・パイプライン実行スクリプト
├── notebooks/         # 探索的分析
├── docs/              # 設計ドキュメント
└── tests/
```
